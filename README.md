# Starting Grid

Brings the online **Starting Grid** setting and **Grid Editor** to the offline Grand Prix.

Grand Prix → Settings → Weekend Structure, with Qualifying Format set to Off:

- **Realistic:** the cars start roughly in performance order (the game's usual grid).
- **Reversed:** the slowest cars start at the front.
- **Random:** a completely random grid.
- **Custom Grid:** set the order yourself in the Grid Editor, like in an online lobby. Opening the Grid Editor
  switches Starting Grid to Custom Grid.

Your Starting Grid and custom order are kept with your Grand Prix save: continue it and they're back, start a new
Grand Prix and it starts fresh, delete or finish it and they go with it.

Works for the 2025 and 2026 seasons, standard weekend. Offline only.
