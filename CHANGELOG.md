# Changelog

## 0.1.1
- Shows as tested on Steam in the launcher's Addon Browser, in the Utility category. Needs launcher 1.8.36 or newer.

## 0.1.0
- First release.
- Starting Grid in the offline Grand Prix menu: Realistic, Reversed, Random and Custom Grid.
- The Grid Editor works offline: move any driver, Randomise Grid, previous position arrows.
- Starting Grid and the custom order are kept with each Grand Prix save.
