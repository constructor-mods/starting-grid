Brings the online **Starting Grid** setting and the **Grid Editor** to the offline **Grand Prix**. Pick how the grid lines up when you race without qualifying, or set the whole order yourself, just like in an online lobby. Works with the 2025 and 2026 seasons.

### Starting Grid
Find it in **Grand Prix → Settings → Weekend Structure**, with **Qualifying Format** set to **Off**.

- **Realistic**: the cars start roughly in performance order, the game's usual grid.
- **Reversed**: the slowest cars start at the front.
- **Random**: a completely random grid, different every race.
- **Custom Grid**: the order you set in the Grid Editor.

### Grid Editor
- The online Grid Editor, now with every driver in your Grand Prix.
- Move any driver up or down, yourself included, or hit **Randomise Grid**.
- The arrows show how far each driver moved from the game's own order.
- Opening the Grid Editor switches Starting Grid to Custom Grid for you.

### Kept with your save
- Your Starting Grid choice and custom order stay with your Grand Prix save, even if you close the game.
- Continue the save and they're back. Start a new Grand Prix and it starts fresh on Realistic.
- Delete the save or finish it, and they go with it.

### Needs
- Swofty Launcher 1.8.10 or newer.
- Offline sessions only, like all modded play.
